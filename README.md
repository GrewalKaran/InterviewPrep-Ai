## 🎬 What's the vibe?
 
Ever spent 3 hours tweaking your resume font size by 0.5pt? Yeah, **never again.**
 
**Resume-GenAI** does the heavy lifting:
- 📤 You upload your old (probably mediocre) resume PDF
- 🧠 Google Gemini AI reads it, understands it, and rewrites it like a pro
- 🎨 It gets rendered into gorgeous, structured HTML
- 🖨️ Puppeteer converts it into a **pixel-perfect downloadable PDF**
- 💼 You send it out and wait for the interviews to roll in
Oh, and there's a whole **AI-powered Interview Report** generator too. Because getting the interview is only half the battle. 😤

## ✨ Features — the good stuff
 
### 🤖 AI & Doc Wizardry
 
| 🪄 Feature | 💬 What it does |
|---|---|
| **Gemini GenAI** | Structured schema prompting → consistent, professional resume gold |
| **PDF Parsing** | Rips text from your uploaded resume via `pdf-parse` |
| **Multer Buffer Uploads** | In-memory file handling — no messy disk writes |
| **Puppeteer PDF Export** | Headless Chrome turns AI-generated HTML into a download-ready PDF |
| **Interview Report Gen** | AI-powered feedback & structured interview analysis |
 
### 🔐 Fort Knox Security
 
| 🛡️ Feature | 💬 What it does |
|---|---|
| **JWT Access + Refresh Tokens** | Stateless sessions via HTTP-only cookies — smooth & secure |
| **Token Blacklisting** | Revoked tokens get yeeted into MongoDB's "nope" list |
| **bcrypt Hashing** | Passwords salted & hashed — no plaintext nonsense here |
| **Protected Routes** | Middleware gatekeeping on both API & frontend |
| **Zod Validation** | Runtime schema checks on every single API input |
 
### 🎨 Frontend Goodies
 
| 🖥️ Feature | 💬 What it does |
|---|---|
| **React 18 + Vite** | Blazing fast dev experience |
| **Feature-Based Architecture** | Auth & Interview-AI are fully isolated modules — clean code vibes |
| **React Context API** | Global state that actually makes sense |
| **SCSS Styling** | Modular stylesheets — no CSS chaos here |
| **React Router v6** | SPA routing with proper protected route wrappers |

## 🚀 Get It Running
 
### Prerequisites — you need these first
 
- 🟢 [Node.js](https://nodejs.org/) `v18+`
- 🍃 [MongoDB](https://www.mongodb.com/) (local or Atlas — your call)
- 🔑 [Google Gemini API Key](https://ai.google.dev/) (free tier is fine to start)
---
 
### Step 1 — Clone it 🐑
 
```bash
git clone https://github.com/KaranGrewal/resumeGenerator-genai.git
cd resumeGenerator-genai
```
 
---
 
### Step 2 — Fire up the Backend 🔥
 
```bash
cd Backend
npm install
```
 
Create a `.env` file in `Backend/`:
 
```env
# 🖥️ Server
PORT=5000
NODE_ENV=development
 
# 🍃 Database
MONGO_URI=mongodb://localhost:27017/resume-genai
 
# 🔑 JWT Secrets (make these long and random!)
JWT_ACCESS_SECRET=your_strong_access_secret_here
JWT_REFRESH_SECRET=your_strong_refresh_secret_here
JWT_ACCESS_EXPIRES=15m
JWT_REFRESH_EXPIRES=7d
 
# 🤖 Google Gemini
GEMINI_API_KEY=your_gemini_api_key_here
 
# 🌐 CORS
CLIENT_URL=http://localhost:5173
```
 
Start it up:
 
```bash
npm run dev # 🔄 dev mode with nodemon (hot reload!)
# or
npm start # 🚢 production mode
```
 
> 🟢 Backend lives at `http://localhost:5000`
 
---
 
### Step 3 — Launch the Frontend 🎨
 
```bash
cd ../Frontend
npm install
npm run dev
```
 
> 🎉 Frontend lives at `http://localhost:5173`

## 🔌 API Reference
 
### 👤 Auth — `/api/user`
 
| Method | Endpoint | What happens | Protected? |
|---|---|---|---|
| `POST` | `/register` | Create a new account | ❌ Public |
| `POST` | `/login` | Get your JWT cookies 🍪 | ❌ Public |
| `POST` | `/logout` | Bye bye session 👋 | ✅ Auth required |
| `POST` | `/refresh` | Swap refresh token for new access token | ✅ Auth required |
 
### 🤖 Interview & Resume — `/api/interview`
 
| Method | Endpoint | What happens | Protected? |
|---|---|---|---|
| `POST` | `/generate` | PDF → parse → Gemini → structured resume ✨ | ✅ Auth required |
| `GET` | `/report` | Fetch your saved interview reports | ✅ Auth required |
| `GET` | `/download` | Grab your AI resume as a PDF | ✅ Auth required |

## 🔐 Auth Flow — How it works under the hood
 
```
🆕 Register
 └─► bcrypt hashes your password
 └─► User safely saved to MongoDB ✅
 
🔑 Login
 └─► Password verified against hash
 └─► JWT access token (15min) + refresh token (7d)
 └─► Both set as HTTP-only cookies 🍪
 
🛡️ Every Protected Request
 └─► auth.middleware.js verifies access token ✅
 
⏰ Token Expired?
 └─► Client calls /refresh
 └─► New access token issued (if refresh token still valid)
 
🚪 Logout
 └─► Refresh token added to MongoDB blacklist
 └─► Cookies cleared — you're out 👋
```

## 🤖 AI Resume Flow — The Magic Pipeline
 
```
📤 Step 1 — User uploads their PDF resume
 │
 ▼
⚙️ Step 2 — file.middleware.js (Multer) catches it as an in-memory buffer
 │
 ▼
📖 Step 3 — pdf-parse reads the buffer, extracts all the raw text
 │
 ▼
🧠 Step 4 — ai.service.js crafts a structured Gemini prompt with a defined JSON schema
 │
 ▼
✨ Step 5 — Gemini returns a validated, polished resume data object
 │
 ▼
🎨 Step 6 — The structured data gets injected into a beautiful HTML resume template
 │
 ▼
🖨️ Step 7 — Puppeteer fires up a headless browser, renders the HTML, exports a PDF
 │
 ▼
📥 Step 8 — PDF streamed to the client as a file download. Done. Hired. 🎉
```
